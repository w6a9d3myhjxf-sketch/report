# 日報・作業確認書 Prototype Ver.50

2026年11月16日現在の公開版コード一式です。

## 配置
ZIPを展開し、index.html、各JS・CSS、assetsフォルダを同じ階層のままGitHubリポジトリにアップロードしてください。ZIPファイルそのものを置くだけではアプリは動作しません。
GitHub Pagesでは配置した階層を公開対象として設定してください。ビルド作業は不要です。
ローカル確認は、このフォルダでHTTPサーバを起動してアクセスしてください（例：python3 -m http.server 8000）。
ログインはWeb Cryptoを使うため、HTTPSまたはlocalhostで確認してください。

## 現在の機能
- 日報・確認書の入力と原本PDF出力。
- 端末内保存、JSONバックアップ・復元。
- 保存時のコマンドプロンプト風表示。
- 指定済みID・パスワードによるブラウザ側の簡易ログイン。
- 工事写真帳は一時停止中。カメラ・黒板機能のJS/CSSは残しています。

## 保存と認証
VPS保存・DB認証・登録端末制限はまだ実装されていません。
現在のログインはブラウザ側の表示制限であり、サーバ側の認証ではありません。公開リポジトリやGitHub Pagesのファイルそのものを秘密にする仕組みではありません。
ChatGPT上の非公開アクセス制限は、このZIPやGitHub Pagesには引き継がれません。
ログイン用パスワードの平文はこのREADMEに含めていません。利用には会話中に指定した認証情報を使います。
保存データはブラウザ・公開URLごとに分かれます。既存サイトのデータは必要に応じJSONでバックアップし、GitHub側で復元してください。実データはZIPに含まれません。
ブラウザからのダウンロード要求後、端末への実ファイル保存はブラウザの操作に従ってください。
